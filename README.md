# ১০ম শ্রেণি Result Portal (প্রবর্তক স্কুল এন্ড কলেজ)

১০ম শ্রেণি (ভোকেশনাল)-এর ফলাফল প্রকাশের জন্য সম্পূর্ণ ফ্রি, GitHub Pages-এ হোস্টেড রেজাল্ট পোর্টাল। একাধিক পরীক্ষার ফলাফল একই সাইটে ড্রপডাউন দিয়ে দেখানো যায় — প্রতিটা পরীক্ষার ডেটা **নিজস্ব আলাদা ফাইলে** থাকে, তাই ম্যানেজ করা সহজ।

## ফাইল কাঠামো

```
index.html          → মূল পেজ (এডিট করার দরকার নেই)
style.css            → ডিজাইন (এডিট করার দরকার নেই)
script.js            → লজিক / GPA হিসাব / ড্রপডাউন (এডিট করার দরকার নেই)
exams.json           → ⭐ পরীক্ষার তালিকা (index) — স্কুলের তথ্য + কোন পরীক্ষার ডেটা কোন ফাইলে
results/
  first_assessment.json  → ⭐ ১ম মূল্যায়ন পরীক্ষার ফলাফল (শুধু এই পরীক্ষার students)
  pre_selection.json     → ⭐ প্রাক-নির্বাচনি পরীক্ষার ফলাফল (শুধু এই পরীক্ষার students)
  ...                     → নতুন পরীক্ষার জন্য নতুন ফাইল এখানেই যোগ হবে
logo.png              → স্কুলের লোগো
excel_to_json.py      → Excel থেকে exams.json + results/<exam-id>.json বানানো/আপডেট করার স্ক্রিপ্ট
```

**কেন আলাদা ফাইল?** আগে সব পরীক্ষার সব শিক্ষার্থীর ডেটা একটাই `results.json`-এ থাকতো, তাই ফাইলটা বড় হয়ে যাচ্ছিল এবং একটা পরীক্ষা আপডেট করতে পুরো ফাইল ওলটপালট করতে হতো। এখন প্রতিটা পরীক্ষার ডেটা `results/` ফোল্ডারে নিজের ফাইলে থাকে — একটা পরীক্ষা যোগ/আপডেট করলে শুধু সেই একটা ফাইল আর `exams.json`-এর এক লাইন বদলায়, বাকি সব ফাইল অক্ষত থাকে। ওয়েবসাইটও প্রথমে শুধু `exams.json` (ছোট) লোড করে, আর যে পরীক্ষা সিলেক্ট করা হয় শুধু তখনই সেই একটা ফাইল লোড হয়।

## বর্তমান অবস্থা

`exams.json`-এ এখন ২টা পরীক্ষার তালিকা আছে, প্রতিটায় ৪৪ জন শিক্ষার্থী:
- **১ম মূল্যায়ন পরীক্ষার ফলাফল** (`first_assessment` → `results/first_assessment.json`)
- **প্রাক-নির্বাচনি পরীক্ষার ফলাফল** (`pre_selection` → `results/pre_selection.json`)

হোমপেজের ড্রপডাউন থেকে যেকোনো একটা বেছে নিয়ে Roll Number দিয়ে সার্চ করা যায়। কোনো পরীক্ষার ফলাফল এখনো প্রকাশিত না থাকলে (`studentCount: 0`) সিলেক্ট করলে "এই পরীক্ষার ফলাফল এখনো প্রকাশিত হয়নি" বার্তা দেখাবে।

- মোবাইল-ফ্রেন্ডলি, সম্পূর্ণ বাংলা ইন্টারফেস
- প্রতিটা পরীক্ষার ডেটা আলাদা ফাইলে, প্রয়োজন হলেই লোড হয় (দ্রুত লোডিং, সহজ ম্যানেজমেন্ট)

## GitHub Pages-এ হোস্ট করবেন কীভাবে

1. `index.html`, `style.css`, `script.js`, `exams.json`, `logo.png`, `excel_to_json.py` এবং পুরো `results/` ফোল্ডার — এই সব কিছু আপনার repository-র **রুট ফোল্ডারে** আপলোড করুন (`results/` একটা ফোল্ডার হিসেবেই থাকবে, ভিতরের ফাইলগুলো আলাদা করে ছড়িয়ে দেবেন না)।
2. Repository-এর **Settings → Pages**-এ যান।
3. **Source: Deploy from a branch**, **Branch: main**, **Folder: / (root)** সিলেক্ট করে **Save** করুন।
4. ১-৩ মিনিট পর ঐ পেজে উপরে একটা সবুজ ব্যানারে লিংক আসবে।
5. লিংকটা রিফ্রেশ (দরকার হলে Ctrl+Shift+R) করে ড্রপডাউন থেকে পরীক্ষা বেছে Roll Number দিয়ে সার্চ করে পরীক্ষা করে দেখুন।

## ফাইলের কাঠামো

**`exams.json`** (index — শুধু তালিকা, শিক্ষার্থীদের ডেটা থাকে না):
```json
{
  "school": { "name": "...", "address": "...", "logo": "logo.png" },
  "exams": [
    { "id": "first_assessment", "label": "১ম মূল্যায়ন পরীক্ষার ফলাফল", "examClass": "...", "file": "results/first_assessment.json", "studentCount": 44 },
    { "id": "pre_selection", "label": "প্রাক-নির্বাচনি পরীক্ষার ফলাফল", "examClass": "...", "file": "results/pre_selection.json", "studentCount": 44 }
  ]
}
```

**`results/<exam-id>.json`** (প্রতিটা পরীক্ষার নিজস্ব ফাইল):
```json
{
  "id": "first_assessment",
  "label": "১ম মূল্যায়ন পরীক্ষার ফলাফল",
  "examClass": "...",
  "students": [ { "roll": "01", "name": "...", "class": "...", "section": "...", "subjects": [ ... ] }, ... ]
}
```

নতুন পরীক্ষা যোগ করতে চাইলে `results/` ফোল্ডারে নতুন একটা ফাইল বানিয়ে `exams.json`-এর `exams` লিস্টে তার তথ্য (নিজস্ব `id`, `label`, `file`, `studentCount`) যোগ হলেই ড্রপডাউনে অটো দেখাবে — কোড এডিট লাগবে না। নিচের স্ক্রিপ্ট দুটো কাজই একসাথে করে দেয়।

## পরবর্তী পরীক্ষার রেজাল্ট প্রকাশ করবেন কীভাবে

তিনভাবে করা যায়:

**ক) Excel ফাইল `marks/` ফোল্ডারে আপলোড করলেই অটো (সবচেয়ে কম ধাপ, আগের মতোই Excel ব্যবহার করে)**
`marks/` ফোল্ডারে পূরণ করা `.xlsx` ফাইল আপলোড করে Commit করলেই GitHub Actions (`.github/workflows/sync-marks.yml`) নিজে থেকে `results/<exam-id>.json` ও `exams.json` বানিয়ে কমিট করে দেয় — কোনো কমান্ড চালানো লাগে না, কোনো Google অ্যাকাউন্টও লাগে না। বিস্তারিত: `marks/README.md`।

**খ) Google Sheets থেকে সরাসরি সিঙ্ক (Excel-এর বদলে Google Sheets ব্যবহার করতে চাইলে)**
`google-sheets-sync/` ফোল্ডারে একটা Google Apps Script দেওয়া আছে — একবার সেটআপ করলে শিক্ষকরা শুধু Google Sheet-এ নম্বর বসিয়ে একটা মেনু-বাটনে ক্লিক করলেই `results/<exam-id>.json` ও `exams.json` সরাসরি GitHub-এ আপডেট হয়ে যায়, ডুপ্লিকেট Roll/ফাঁকা নম্বরের সতর্কতাসহ। বিস্তারিত ধাপে ধাপে গাইড: `google-sheets-sync/README.md`।

**গ) `excel_to_json.py` স্ক্রিপ্ট নিজে কম্পিউটারে চালিয়ে**

নতুন পরীক্ষার Excel ফাইল পূরণ করে আমাকে দিলে আমি ফাইল বানিয়ে দেব, অথবা নিজে কমান্ড চালাতে পারেন:

```bash
python3 excel_to_json.py নতুন_মার্কশিট.xlsx \
  --sheet pretest \
  --exam-id half_yearly \
  --exam-label "অর্ধবার্ষিক পরীক্ষার ফলাফল" \
  --exam-name "অর্ধবার্ষিক পরীক্ষা-২০২৬" \
  --exam-class "১০ম" --section "ভোকেশনাল"
```

এই একটা কমান্ড দুটো ফাইল লেখে/আপডেট করে:
- `results/half_yearly.json` (নতুন ফাইল, ওই পরীক্ষার সব শিক্ষার্থীর ডেটা)
- `exams.json` (শুধু `half_yearly`-এর এন্ট্রি যোগ/আপডেট হয়, বাকি পরীক্ষাগুলো অক্ষত থাকে)

⚠️ **গুরুত্বপূর্ণ:**
- `--exam-id` প্রতিটা পরীক্ষার জন্য আলাদা ও স্থায়ী রাখুন (যেমন `first_assessment`, `pre_selection`, `half_yearly`, `annual`) — একই id দিলে সেই পরীক্ষার শুধু নিজের ফাইলটা রিপ্লেস হবে, অন্য পরীক্ষা ছোঁয়া লাগবে না।
- Roll Number কলাম না থাকলে `--roll-file` ও `--roll-sheet` দিয়ে একটা Roll-list শিট বসিয়ে দিতে হবে (রোল ও নাম একই ক্রমে থাকতে হবে)।
- প্রতিটি বিষয়ের গ্রেড Excel-এর নিজস্ব IF-ফর্মুলা থেকে পড়া হয়, তাই ভিন্ন ভিন্ন এক্সামে ভিন্ন গ্রেডিং স্কেল থাকলেও সঠিকভাবে মিলবে।
- স্ক্রিপ্ট চালানোর পর GitHub-এ শুধু **বদলে যাওয়া দুইটা ফাইল** (`results/<exam-id>.json` আর `exams.json`) আপলোড করে **Commit** করলেই নতুন পরীক্ষা ড্রপডাউনে দেখাবে ও ফলাফল লাইভ হয়ে যাবে। বাকি ফাইল (`index.html`, `style.css`, `script.js`, `logo.png`, অন্য পরীক্ষার ফাইল) কখনো ছোঁয়া লাগবে না।
- স্কুলের নাম/ঠিকানা বদলাতে চাইলে `--school-name` ও `--school-address` দিন — এটা `exams.json`-এর `school` অংশে আপডেট হবে।

**স্বয়ংক্রিয় ডেটা-যাচাই (admin validation):** স্ক্রিপ্ট চালানো শেষে এখন নিজে থেকেই কিছু সাধারণ ভুল চেক করে সতর্ক করে —
- ডুপ্লিকেট Roll Number (একই Roll একাধিক শিক্ষার্থীর নামে থাকলে)
- কোনো বিষয়ের 'মোট নম্বর' পুরো কলামেই ফাঁকা (কলাম ম্যাপিং ভুল হওয়ার লক্ষণ)
- কোনো বিষয়ে অনেক শিক্ষার্থীর 'প্রাপ্ত নম্বর' ফাঁকা (0 ধরে হিসাব হয়েছে)
- কোনো বিষয়ের গ্রেড-কলামে IF-ফর্মুলা না পাওয়া গেলে (ফলে ডিফল্ট গ্রেডিং টেবিল ব্যবহার হয়েছে)
- Roll কলাম/রোস্টার ফাইল কিছুই না থাকলে (স্বয়ংক্রিয় 1,2,3... নম্বরিং হয়েছে)

এগুলো টার্মিনালে "⚠️ সতর্কতা" হিসেবে দেখাবে — এরপরও ফাইল লেখা হয়ে যায় (ব্লক করে না), শুধু জানিয়ে দেয় যাতে GitHub-এ আপলোডের আগে একবার চোখ বুলিয়ে নেওয়া যায়।
