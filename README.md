# ১০ম শ্রেণি Result Portal (প্রবর্তক স্কুল এন্ড কলেজ)

১০ম শ্রেণি (ভোকেশনাল)-এর ফলাফল প্রকাশের জন্য সম্পূর্ণ ফ্রি, GitHub Pages-এ হোস্টেড রেজাল্ট পোর্টাল। একাধিক পরীক্ষার ফলাফল একই সাইটে ড্রপডাউন দিয়ে দেখানো যায়।

## ফাইল কাঠামো

```
index.html       → মূল পেজ (এডিট করার দরকার নেই)
style.css        → ডিজাইন (এডিট করার দরকার নেই)
script.js        → লজিক / GPA হিসাব / ড্রপডাউন (এডিট করার দরকার নেই)
results.json     → ⭐ সব পরীক্ষার রেজাল্ট ডেটা (এখানেই শুধু আপডেট করবেন)
logo.png         → স্কুলের লোগো
excel_to_json.py → Excel থেকে results.json বানানো/আপডেট করার স্ক্রিপ্ট
```

## বর্তমান অবস্থা

`results.json`-এ এখন ২টা পরীক্ষার ফলাফল প্রকাশিত আছে, প্রতিটায় ৪৪ জন শিক্ষার্থী:
- **১ম মূল্যায়ন পরীক্ষার ফলাফল** (`first_assessment`)
- **প্রাক-নির্বাচনি পরীক্ষার ফলাফল** (`pre_selection`)

হোমপেজের ড্রপডাউন থেকে যেকোনো একটা বেছে নিয়ে Roll Number দিয়ে সার্চ করা যায়। কোনো পরীক্ষার ফলাফল এখনো না থাকলে (`students: []`) সিলেক্ট করলে "এই পরীক্ষার ফলাফল এখনো প্রকাশিত হয়নি" বার্তা দেখাবে।

## GitHub Pages-এ হোস্ট করবেন কীভাবে

1. এই ৬টা ফাইল আপনার repository-র **রুট ফোল্ডারে** আপলোড করুন (কোনো সাব-ফোল্ডারে না)।
2. Repository-এর **Settings → Pages**-এ যান।
3. **Source: Deploy from a branch**, **Branch: main**, **Folder: / (root)** সিলেক্ট করে **Save** করুন।
4. ১-৩ মিনিট পর ঐ পেজে উপরে একটা সবুজ ব্যানারে লিংক আসবে।
5. লিংকটা রিফ্রেশ (দরকার হলে Ctrl+Shift+R) করে ড্রপডাউন থেকে পরীক্ষা বেছে Roll Number দিয়ে সার্চ করে পরীক্ষা করে দেখুন।

## `results.json`-এর কাঠামো

```json
{
  "school": { "name": "...", "address": "...", "logo": "logo.png" },
  "exams": [
    { "id": "first_assessment", "label": "১ম মূল্যায়ন পরীক্ষার ফলাফল", "examClass": "...", "students": [ ... ] },
    { "id": "pre_selection", "label": "প্রাক-নির্বাচনি পরীক্ষার ফলাফল", "examClass": "...", "students": [ ... ] }
  ]
}
```
নতুন পরীক্ষা যোগ করতে চাইলে `exams` লিস্টে নতুন একটা অবজেক্ট (নিজস্ব `id`, `label`, `students`) যোগ হলেই ড্রপডাউনে অটো দেখাবে — কোড এডিট লাগবে না।

## পরবর্তী পরীক্ষার রেজাল্ট প্রকাশ করবেন কীভাবে

নতুন পরীক্ষার Excel ফাইল পূরণ করে আমাকে দিলে আমি `results.json` আপডেট করে দেব, অথবা নিজে কমান্ড চালাতে পারেন:

```bash
python3 excel_to_json.py নতুন_মার্কশিট.xlsx results.json \
  --sheet pretest \
  --exam-id half_yearly \
  --exam-label "অর্ধবার্ষিক পরীক্ষার ফলাফল" \
  --exam-name "অর্ধবার্ষিক পরীক্ষা-২০২৬" \
  --exam-class "১০ম" --section "ভোকেশনাল"
```

⚠️ **গুরুত্বপূর্ণ:**
- `results.json` **আউটপুট ফাইল হিসেবে দিন** (উপরের কমান্ডের মতো) — স্ক্রিপ্টটা শুধু ঐ `--exam-id`-এর ডেটা আপডেট/যোগ করবে, বাকি পরীক্ষার ডেটা অক্ষত থাকবে।
- `--exam-id` প্রতিটা পরীক্ষার জন্য আলাদা ও স্থায়ী রাখুন (যেমন `first_assessment`, `pre_selection`, `half_yearly`, `annual`) — একই id দিলে সেই পরীক্ষার পুরনো ডেটা রিপ্লেস হয়ে যাবে।
- Roll Number কলাম না থাকলে `--roll-file` ও `--roll-sheet` দিয়ে একটা Roll-list শিট বসিয়ে দিতে হবে (রোল ও নাম একই ক্রমে থাকতে হবে)।
- প্রতিটি বিষয়ের গ্রেড Excel-এর নিজস্ব IF-ফর্মুলা থেকে পড়া হয়, তাই ভিন্ন ভিন্ন এক্সামে ভিন্ন গ্রেডিং স্কেল থাকলেও সঠিকভাবে মিলবে।

নতুন `results.json` বানানোর পর সেটা GitHub-এ **Upload files → same name → Commit** করে replace করলেই নতুন পরীক্ষা ড্রপডাউনে দেখাবে ও ফলাফল লাইভ হয়ে যাবে। বাকি ফাইল (`index.html`, `style.css`, `script.js`, `logo.png`) কখনো ছোঁয়া লাগবে না।

## অন্যান্য ছোট পরিবর্তন (স্কুলের নাম/লোগো/ফেসবুক লিংক ইত্যাদি)

- স্কুলের নাম/ঠিকানা: `results.json`-এর `school` অংশে
- লোগো: `logo.png` রিপ্লেস করলেই বদলে যাবে
- ফুটারের ফেসবুক লিংক: `index.html`-এ ফুটার লাইনে `href="..."` বদলে দিলেই হবে
