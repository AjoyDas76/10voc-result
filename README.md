# ১০ম শ্রেণি Result Portal (প্রাক-নির্বাচনি পরীক্ষা)

এই রিপোতে ১০ম শ্রেণি (ভোকেশনাল)-এর **প্রাক-নির্বাচনি পরীক্ষা-২০২৬**-এর ফলাফল প্রকাশের জন্য সম্পূর্ণ রেডি ফাইল আছে।

## ফাইল কাঠামো

```
index.html     → মূল পেজ (এডিট করার দরকার নেই)
style.css      → ডিজাইন (এডিট করার দরকার নেই)
script.js      → লজিক / GPA হিসাব (এডিট করার দরকার নেই)
results.json   → ⭐ প্রাক-নির্বাচনি পরীক্ষার ৪৪ জন শিক্ষার্থীর রেজাল্ট (এখানেই ডেটা)
logo.png       → স্কুলের লোগো (প্রবর্তক স্কুল এন্ড কলেজ)
excel_to_json.py → পরবর্তী পরীক্ষার Excel থেকে results.json বানানোর স্ক্রিপ্ট
```

## GitHub Pages-এ হোস্ট করবেন কীভাবে

1. এই ৬টা ফাইল (`index.html`, `style.css`, `script.js`, `results.json`, `logo.png`, `excel_to_json.py`) আপনার নতুন repository-র **রুট ফোল্ডারে** আপলোড করুন (কোনো সাব-ফোল্ডারে না)।
2. Repository-এর **Settings → Pages**-এ যান।
3. **Source: Deploy from a branch**, **Branch: main**, **Folder: / (root)** সিলেক্ট করে **Save** করুন।
4. ১-৩ মিনিট পর ঐ পেজেই উপরে একটা সবুজ ব্যানারে লিংক আসবে — যেমন `https://your-username.github.io/repo-name/`।
5. লিংকটা রিফ্রেশ (দরকার হলে Ctrl+Shift+R) করে ২-১ জনের Roll Number দিয়ে সার্চ করে পরীক্ষা করে দেখুন।

## যাচাই করার জন্য নমুনা তথ্য

- মোট শিক্ষার্থী: ৪৪ জন, Roll `01` থেকে শুরু
- Roll `01` = Pranti Shil (H)
- Roll `04` = Srabonti Roy

## পরীক্ষা বাছাই ড্রপডাউন (নতুন ফিচার)

হোমপেজে এখন একটা ড্রপডাউন আছে যেখান থেকে পরীক্ষা বেছে নেওয়া যায়:
- **১ম মূল্যায়ন পরীক্ষার ফলাফল** (এখনো খালি — Excel দিলে যোগ করে দেব)
- **প্রাক-নির্বাচনি পরীক্ষার ফলাফল** (বর্তমানে প্রকাশিত)

যে পরীক্ষায় এখনো ফলাফল যোগ করা হয়নি, সেটা সিলেক্ট করলে "এই পরীক্ষার ফলাফল এখনো প্রকাশিত হয়নি" — এই বার্তা দেখাবে।

`results.json`-এর কাঠামো এখন এরকম:
```json
{
  "school": { "name": "...", "address": "...", "logo": "logo.png" },
  "exams": [
    { "id": "first_assessment", "label": "১ম মূল্যায়ন পরীক্ষার ফলাফল", "examClass": "...", "students": [] },
    { "id": "pre_selection", "label": "প্রাক-নির্বাচনি পরীক্ষার ফলাফল", "examClass": "...", "students": [ ... ] }
  ]
}
```
নতুন কোনো পরীক্ষা যোগ করতে চাইলে `exams` লিস্টে নতুন একটা অবজেক্ট (নিজস্ব `id`, `label`, `students`) যোগ করলেই ড্রপডাউনে অটো দেখাবে — কোড এডিট লাগবে না।

## পরবর্তী পরীক্ষার রেজাল্ট প্রকাশ করবেন কীভাবে

নতুন পরীক্ষার Excel ফাইল পূরণ করে আমাকে দিলে আমি `results.json`-এ যোগ করে দেব, অথবা নিজে কমান্ড চালাতে পারেন:

```bash
python3 excel_to_json.py নতুন_মার্কশিট.xlsx results.json \
  --sheet pretest \
  --exam-id first_assessment \
  --exam-label "১ম মূল্যায়ন পরীক্ষার ফলাফল" \
  --exam-name "১ম মূল্যায়ন পরীক্ষা-২০২৬" \
  --exam-class "১০ম" --section "ভোকেশনাল"
```

⚠️ **গুরুত্বপূর্ণ:**
- `results.json` **আউটপুট ফাইল হিসেবে দিন** (উপরের কমান্ডের মতো) — স্ক্রিপ্টটা বুদ্ধিমানের মতো শুধু ঐ `--exam-id`-এর ডেটা আপডেট করবে, বাকি পরীক্ষার ডেটা অক্ষত থাকবে।
- `--exam-id` প্রতিটা পরীক্ষার জন্য আলাদা ও স্থায়ী রাখুন (যেমন `first_assessment`, `pre_selection`, `half_yearly`, `annual`) — একই id দিলে সেই পরীক্ষার পুরনো ডেটা রিপ্লেস হয়ে যাবে।
- Roll Number কলাম না থাকলে `--roll-file` ও `--roll-sheet` দিয়ে একটা Roll-list শিট বসিয়ে দিতে হবে।

নতুন `results.json` বানানোর পর সেটা GitHub-এ **Upload files → same name → Commit** করে replace করলেই নতুন পরীক্ষা ড্রপডাউনে দেখাবে ও ফলাফল লাইভ হয়ে যাবে। বাকি ফাইল (`index.html`, `style.css`, `script.js`, `logo.png`) কখনো ছোঁয়া লাগবে না।
