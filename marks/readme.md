# marks/ — GitHub Actions অটো-সিঙ্ক ফোল্ডার

এই ফোল্ডারে একটা পূরণ করা মার্কশিট Excel ফাইল (`marksheet_template.xlsx`-এর ফরম্যাটে) আপলোড করে **Commit** করলেই GitHub নিজে থেকে `results/<exam-id>.json` ও `exams.json` বানিয়ে/আপডেট করে দেবে — কোনো কমান্ড চালানো লাগবে না।

⚠️ **খালি টেমপ্লেট ফাইল (`marksheet_template.xlsx`) এই ফোল্ডারে আপলোড করবেন না** — এটা শুধু রেফারেন্সের জন্য রুটে/নিজের কম্পিউটারে রাখুন, এখানে আপলোড করলে workflow সেটাকেও একটা আসল পরীক্ষা (উদাহরণ-রোল 01/02 সহ) হিসেবে ওয়েবসাইটে পাবলিশ করে দেবে। এই ফোল্ডারে শুধু **পূরণ করা, আসল নম্বরসহ** ফাইল আপলোড করুন।

## ব্যবহার

1. ফাইলের নামই Exam ID হবে — তাই ফাইলটার নাম রাখুন ঠিক যা Exam ID হিসেবে চান, ইংরেজিতে, যেমন:
   - `first_assessment.xlsx`
   - `pre_selection.xlsx`
   - `half_yearly.xlsx`
2. এই ফোল্ডারে আপলোড করে **Commit changes** করুন।
3. ১-২ মিনিট পর repository-র **Actions** ট্যাবে "Sync marks to result files" workflow রান হবে, `results/<exam-id>.json` ও `exams.json` নিজে থেকে আপডেট হয়ে কমিট হয়ে যাবে।
4. ওয়েবসাইট রিফ্রেশ করলে ড্রপডাউনে পরীক্ষাটা দেখাবে।

## নতুন পরীক্ষার নাম/ক্লাস ঠিক করা (ঐচ্ছিক, কিন্তু প্রথমবার ভালো)

প্রথমবার কোনো নতুন Exam ID আপলোড করলে ডিফল্ট হিসেবে "১০ম শ্রেণি (ভোকেশনাল)" আর লেবেল হিসেবে ফাইলের নামটাই (যেমন `first_assessment`) ব্যবহার হবে — ড্রপডাউনে একটু আনপ্রফেশনাল দেখাবে। সঠিক বাংলা লেবেল দিতে একই নামের একটা `.meta.json` ফাইল পাশে আপলোড করুন:

**`marks/first_assessment.meta.json`:**
```json
{
  "label": "১ম মূল্যায়ন পরীক্ষার ফলাফল",
  "class": "১০ম",
  "section": "ভোকেশনাল"
}
```

এটা **শুধু প্রথমবার** লাগে — পরে একই `first_assessment.xlsx` ফাইল আপডেট করে আবার আপলোড করলে আগের লেবেল/ক্লাস এমনিতেই থেকে যাবে, `.meta.json` আর লাগবে না (চাইলে ফেলে রাখলেও সমস্যা নেই)।

## কী হবে যদি...

- **একই Exam ID-তে ফাইল আবার আপলোড করেন** → শুধু সেই একটা পরীক্ষার ডেটা রিপ্লেস হবে, বাকি সব পরীক্ষা অক্ষত থাকবে।
- **ফাইলে ভুল থাকে** (ডুপ্লিকেট Roll, ফাঁকা নম্বর ইত্যাদি) → workflow তবুও ফাইল লিখবে, কিন্তু Actions ট্যাবের লগে ⚠️ সতর্কতা দেখাবে — মাঝে মাঝে একবার লগ চেক করে নেওয়া ভালো।
- **Excel-এর লেআউট চেনা না গেলে** (যেমন 'নাম' কলাম খুঁজে না পেলে) → সেই একটা ফাইল স্কিপ হয়ে লগে ❌ এরর দেখাবে, বাকি ফাইলগুলো ঠিকমতো প্রসেস হবে।

## লগ কোথায় দেখবেন

repository-র উপরে **Actions** ট্যাব → সবচেয়ে উপরের রান → **sync** job → **"Convert marks/*.xlsx..."** ধাপ ক্লিক করলে পুরো আউটপুট (কোন বিষয় ডিটেক্ট হলো, কী সতর্কতা এলো) দেখা যাবে।
