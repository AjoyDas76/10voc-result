# Google Sheets → ওয়েবসাইট সরাসরি সিঙ্ক

এই স্ক্রিপ্ট দিয়ে `excel_to_json.py` লোকাল কম্পিউটারে চালানোর দরকার নেই — শিক্ষকরা সরাসরি Google Sheet-এ নম্বর বসিয়ে একটা মেনু বাটনে ক্লিক করলেই ওয়েবসাইট (GitHub-এর `results/<exam-id>.json` ও `exams.json`) আপডেট হয়ে যাবে।

## কীভাবে কাজ করে

1. আপনার আগের মার্কশিট Excel ফাইলটাই Google Sheets-এ আপলোড/কপি করুন (একই লেআউট — নাম/Roll কলাম, প্রতিটা বিষয়ের মোট নম্বর/প্রাপ্ত নম্বর/গ্রেড ব্লক)।
2. এই ফোল্ডারের `Code.gs` স্ক্রিপ্টটা সেই স্প্রেডশিটে যোগ করুন (নিচে ধাপ দেওয়া আছে)।
3. একবার GitHub টোকেন সেট করে দিলে, প্রতিটা পরীক্ষার শিট থেকে "🎓 রেজাল্ট পোর্টাল → 🚀 এই শিট ওয়েবসাইটে সিঙ্ক করুন" ক্লিক করলেই ডেটা যাচাই (ডুপ্লিকেট Roll, ফাঁকা নম্বর ইত্যাদি) হয়ে সরাসরি GitHub-এ কমিট হয়ে যাবে।

## এক-বার সেটআপ (ধাপে ধাপে)

### ১) স্প্রেডশিট বানান
- Google Sheets-এ নতুন একটা স্প্রেডশিট বানান (অথবা আপনার বিদ্যমান মার্কশিট Excel ফাইলটা Google Sheets-এ import করুন)।
- প্রতিটা পরীক্ষার জন্য একটা করে ট্যাব/শিট রাখুন — যেমন `first_assessment`, `pre_selection` — প্রতিটাতে সেই পরীক্ষার নাম/Roll/বিষয়ভিত্তিক নম্বরের টেবিল থাকবে (আগের Excel-এর মতোই লেআউট)।

### ২) স্ক্রিপ্ট যোগ করুন
- স্প্রেডশিট খুলে উপরে **Extensions → Apps Script** এ যান।
- ডিফল্ট `Code.gs` ফাইলের সব লেখা মুছে এই ফোল্ডারের `Code.gs`-এর পুরো কনটেন্ট পেস্ট করুন।
- উপরে **Save (💾)** করুন, তারপর স্প্রেডশিটে ফিরে গিয়ে পেজ রিফ্রেশ করুন — কিছুক্ষণ পর উপরে **"🎓 রেজাল্ট পোর্টাল"** নামে একটা নতুন মেনু দেখাবে।

### ৩) GitHub Personal Access Token বানান
- GitHub-এ লগইন করে **Settings → Developer settings → Personal access tokens → Fine-grained tokens** (অথবা Classic token) এ যান।
- **Generate new token** করুন, শুধু আপনার result-portal repository-টার জন্য access দিন, permission হিসেবে **Contents: Read and write** দিন।
- টোকেনটা কপি করে রাখুন (এটা একবারই দেখাবে)।

### ৪) স্প্রেডশিটে টোকেন ও রিপো সেট করুন
- স্প্রেডশিটে **🎓 রেজাল্ট পোর্টাল → 🔑 GitHub টোকেন সেট করুন** এ ক্লিক করে টোকেনটা পেস্ট করুন। (এটা কোনো সেলে দেখা যাবে না, শুধু স্ক্রিপ্টের নিরাপদ প্রপার্টিতে জমা থাকবে।)
- **🎓 রেজাল্ট পোর্টাল → ⚙️ সেটিংস শিট খুলুন/বানান** এ ক্লিক করুন — এটা একটা `Settings` নামের শিট বানাবে। সেখানে পূরণ করুন:
  - GitHub owner (যেমন আপনার GitHub ইউজারনেম)
  - Repository নাম (যেমন `10voc-result`)
  - Branch (সাধারণত `main`)
  - স্কুলের নাম ও ঠিকানা

প্রথমবার স্ক্রিপ্ট চালানোর সময় Google একটা পারমিশন-অনুমোদন চাইবে (এটা শুধু আপনার নিজের স্প্রেডশিট এবং GitHub-এ যাওয়ার জন্য) — **Advanced → Go to (project name) → Allow** করে দিন।

## প্রতিটা পরীক্ষার জন্য ব্যবহার

1. যে শিট ট্যাবে সেই পরীক্ষার নম্বর আছে সেটা খুলুন, নম্বর বসান/আপডেট করুন।
2. **🎓 রেজাল্ট পোর্টাল → 🚀 এই শিট ওয়েবসাইটে সিঙ্ক করুন** ক্লিক করুন।
3. প্রথমবার এই ট্যাবের জন্য Exam ID / Label / Class / Section জিজ্ঞাসা করবে (একবারই — `Settings` শিটের নিচের টেবিলে সেভ হয়ে যাবে, পরেরবার আর জিজ্ঞাসা করবে না)।
4. ডুপ্লিকেট Roll বা ফাঁকা নম্বরের মতো সমস্যা থাকলে একটা সতর্কতার তালিকা দেখাবে — চাইলে তখনই বাতিল করে শিট ঠিক করে আবার চালাতে পারেন, অথবা "হ্যাঁ" দিয়ে এগিয়ে যেতে পারেন।
5. সফল হলে `results/<exam-id>.json` ও `exams.json` সরাসরি GitHub-এ কমিট হয়ে যাবে — ১-২ মিনিটের মধ্যে ওয়েবসাইটে দেখা যাবে।

## `Settings` শিটের এক্সাম-ম্যাপিং টেবিল

`Settings` শিটের নিচের দিকে একটা টেবিল অটো তৈরি হয়:

| শিট ট্যাবের নাম | Exam ID | Exam Label | Exam Class | Section |
|---|---|---|---|---|
| first_assessment | first_assessment | ১ম মূল্যায়ন পরীক্ষার ফলাফল | ১০ম | ভোকেশনাল |

চাইলে এই টেবিলের সারিগুলো সরাসরি এডিটও করতে পারেন (যেমন Exam Label বদলাতে চাইলে)।

## সীমাবদ্ধতা / যা মাথায় রাখবেন

- এটা **ম্যানুয়াল বাটনে ক্লিক করে** সিঙ্ক করে, প্রতিটা কী-স্ট্রোকে অটোমেটিক সিঙ্ক করে না — ইচ্ছাকৃতভাবেই এমন রাখা হয়েছে, যাতে নম্বর টাইপ করার মাঝপথে ভুল ডেটা ওয়েবসাইটে চলে না যায়। নম্বর দেওয়া শেষ হলে তারপর সিঙ্ক করুন।
- সম্পূর্ণ হাতে-ছাড়া (fully automatic) চাইলে Apps Script-এর **Triggers (⏰)** থেকে `syncActiveSheet` ফাংশনের জন্য একটা টাইম-বেসড ট্রিগার (যেমন প্রতি ৩০ মিনিটে) বসাতে পারেন — তবে তখন প্রথমবার ম্যাপিং-প্রম্পট আসবে না (Settings শিটে আগে থেকে সারি থাকতে হবে) এবং সতর্কতা থাকলেও নিজে থেকে "হ্যাঁ" ধরে নিয়ে এগিয়ে যাবে।
- GitHub টোকেনের মেয়াদ (expiration) থাকলে মেয়াদ শেষ হলে আবার নতুন টোকেন বানিয়ে "🔑 GitHub টোকেন সেট করুন" দিয়ে আপডেট করতে হবে।
